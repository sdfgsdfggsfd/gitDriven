# Code of conduct

This is a project for having fun together. It applies to GitHub, the server and Discord.

- **Be kind.** Critique code, not people. Everyone started somewhere.
- **Pranks yes, sabotage no.** Funny features are welcome; taking the server down or
  destroying other people's work on purpose is not.
- **No harassment, bigotry or inappropriate content**, in code, messages or builds.
- **Respect the approvers' decisions.** Disagree? Talk it through in the issue/PR.

Problems: talk to an approver (see `.github/CODEOWNERS`). Anyone who breaks the rules
may lose access to the repository and the server.
